A guide to the dihiggs repository

This repository models the gluon-fusion di-Higgs cross section, dσ/dmhh, as a function of five HEFT Wilson coefficients, from 4,999 POWHEG NLO spectra. It also holds the notes that record how the model was built and tested. This page tells you what to read first, what to run, and where everything lives.

P. Bhat (Fermilab), N. De Filippis (Politecnico di Bari), K.F. Johnson, H.B. Prosper, R. Starnes (Florida State University)

θ = (κλ, ct, ctt, cggh, cgghh)the five HEFT coefficients
dσ/dm = Σ Ci(θ) ai(m)23 known monomials Ci, 23 unknown functions ai
80 bins, 255–1455 GeV15 GeV each; 40,000 events per spectrum
3,989 + 1,000spectra for fitting + test spectra never used in fitting

I want to use the model

The primary model needs only NumPy and SciPy. Run from the repository root:

from dihiggs.smooth import SmoothHEFT
model = SmoothHEFT.load(
  'code/runs/SMOOTH_J40/smooth_model.npz')
theta = [1, 1, 0, 0, 0]          # the SM
sigma, sd = model.spectrum(theta)
# pb per 15 GeV bin, 255-1455 GeV; sd includes
# the fit and model-error uncertainties

Use it on 250–1455 GeV only. For bins wider than 15 GeV, sum the 15 GeV bins (dihiggs_model.pdf, section 8).

How good are they?

The pipeline

Run the notebooks from code/, in this order. Each writes its results into a run folder under code/runs/.

  1. 1

    heft_prepare_data.ipynb

    Splits the POWHEG spectra into 1,000 test spectra and the training rows (one row per bin).

    Writes data/heft_wide_gauss_testdata_13TeV.csv and data/heft_wide_gauss_traindata_13TeV.csv.gz. Both are already in the repository, so you only need this step to change the split.

  2. 2

    Fit a model

    primary heft_smooth.ipynb

    Fits the smooth model and its model-error coefficient ε(m). About 75 s on a laptop CPU.

    Writes runs/SMOOTH_J40/.

    cross-check heft_train.ipynb, then heft_finetune.ipynb

    Trains the density network with an L1 loss (MODEL = 'density'; use a GPU), then fine-tunes it (DELTAS = [2], CURV_LAMBDAS = [1e-6]; about a minute on a GPU).

    Writes runs/DENS_L1_SiLU_thr/, then runs/FTD_SiLU_huber_d2_pearson_curv1e-06/.

  3. 3

    heft_density_eval.ipynb

    Evaluates the density networks exactly as the smooth model was evaluated: −2 ln λ, calibrated pulls, comparison of the densities. About 5 minutes on a laptop.

    Prints the tables and writes the figures in docs/density/.

  4. 4

    Paper figures: docs/paper/fig_*.py

    Each script makes one figure. Run them from docs/paper/; they share smooth_common.py, which reads the smooth model and the test spectra from the repository.

Terms used in the notes

Bin integral
The cross section in a bin, ∫ dσ/dm dm over the bin. POWHEG gives bin integrals, so both current models are compared with POWHEG through them, never through the value at the bin centre.
Threshold factor φ(m)
√(1 − 4mh2/m2), the Higgs velocity in the hh rest frame. It makes the density vanish at mhh = 250 GeV, as two-body phase space does.
−2 ln λ
The likelihood-ratio statistic for a count n and a prediction μ: −2 ln[Poisson(n; μ)/Poisson(n; n)]. Its mean is 1 for a correct model. The notes use it instead of a χ2 that divides by the observed count, which favours predictions biased low.
Free fit
23 independent numbers per bin, fitted to the training rows. The best that any model of the 23-term form can do, so it serves as the benchmark.
Model-error term
The systematic uncertainty, ε(m) Σi |Ci Ai|. It covers POWHEG's small departures from the 23-term form, which are largest where the terms cancel. ε is 0.08% at threshold and 0.28% at 600 GeV.
Cancellation ratio
A spectrum's total cross section divided by the sum of the magnitudes of its 23 terms. It is near 1 when the terms add and small when they cancel.
Test spectra, quick-test rows
The 1,000 test spectra are never used in fitting; all the headline numbers come from them. The quick-test rows are bins of the other spectra that are also never fitted; they set ε(m).
Pull
(POWHEG − prediction) divided by the total uncertainty. Its standard deviation should be 1 if the uncertainties are right.

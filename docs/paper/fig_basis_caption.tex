\caption{The basis of the smooth model. Top: the 40 cubic B-splines $B_j(m_{hh})$, coloured by
index $j$. The breakpoints (ticks) are uniform in $\sqrt{m_{hh}-250~\mathrm{GeV}}$, so they are dense
just above threshold (inset), where the spectra change fastest. The knot vector is clamped (each end
point repeated three more times), so the $B_j$ sum to one everywhere on $[250, 1500]$~GeV and only
$B_1$ ($B_{40}$) is non-zero at the lower (upper) end. Bottom: the basis functions
$\phi(m_{hh})B_j(m_{hh})$ multiplied by the coefficients $\beta_{ij}$ in
$a_i(m_{hh}) = \phi(m_{hh})\sum_j \beta_{ij}B_j(m_{hh})$, with the threshold factor
$\phi = \sqrt{1-4m_h^2/m_{hh}^2}$ (dashed). The model is used only below 1455~GeV; the shaded
region is beyond the last bin.}
